¿Qué es tomar una decisión en un programa?

Guía 6 – Estructuras Selectivas

En la vida diaria tomamos decisiones todo el tiempo. Por ejemplo:

?
Si está lloviendo, entonces llevo paraguas. Si no, salgo sin paraguas.
?
Si mi nota es mayor o igual a 3.0, entonces apruebo. Si no, repruebo.

En lenguaje C esto se escribe con estructuras condicionales: el programa decide qué instrucciones ejecutar.

Las tres formas que veremos hoy

  • if → cuando solo hay una posibilidad.
  • if – else → cuando hay dos caminos.
  • if – else if – else → cuando hay tres o más caminos.

¡Cuidado!

Estructura 1 · Solo if (una sola posibilidad)

Se ejecuta el bloque solo si la condición es verdadera. Si es falsa, el programa sigue de largo.

Paso a paso

1
Escribimos la palabra if.
2
Abrimos paréntesis y escribimos la condición: (edad >= 18).
3
Abrimos llaves { } y dentro ponemos lo que debe pasar si se cumple.
#include <stdio.h>

int main() {
    int edad = 20;

    // Condición: ¿la edad es mayor o igual a 18?
    if (edad >= 18) {
        printf("Puede votar\n");
    }

    printf("Fin del programa\n");
    return 0;
}

Salida esperada

Puede votar

Fin del programa

Reto rápido

Cambia la edad a 15 y vuelve a compilar. ¿Por qué ya no aparece "Puede votar"?

Estructura 2 · if – else (dos caminos)

Cuando hay dos posibilidades y siempre se debe ejecutar una de las dos.

Paso a paso

1
Escribimos if (condición) con su bloque de llaves.
2
Después escribimos else (sin condición) y su bloque.
3
El bloque del else se ejecuta cuando la condición del if fue falsa.
#include <stdio.h>

int main() {
    float nota = 3.8;

    if (nota >= 3.0) {
        printf("Aprobado\n");
    } else {
        printf("Reprobado\n");
    }

    return 0;
}

Salida esperada

Aprobado

Reto en clase

Pide la nota con scanf y prueba con 2.5, 3.0 y 4.5. ¿Qué aparece en cada caso?

Estructura 3 · if – else if – else (tres o más caminos)

Se usa cuando hay varias posibilidades. Las condiciones se revisan en orden, de arriba hacia abajo.

1
Se revisa la primera condición del if.
2
Si es falsa, se revisa la siguiente con else if.
3
Se pueden poner varios else if seguidos.
4
El else final se ejecuta solo si ninguna anterior se cumplió.
#include <stdio.h>

int main() {
    int edad;
    printf("Ingrese su edad: ");
    scanf("%d", &edad);

    if (edad < 0) {
        printf("Edad no valida\n");
    } else if (edad >= 18) {
        printf("Puede votar\n");
    } else {
        printf("No puede votar aun\n");
    }

    return 0;
}

Importante

El orden sí importa. Si pusiéramos edad >= 18 antes que edad < 0, el programa nunca detectaría edades negativas.

Jerarquía de operadores y uso de paréntesis

Cuando una condición tiene varias operaciones, el computador las resuelve en un orden establecido.

OrdenOperadoresEjemplo
1 (primero)( )(a + b)
2!!activo
3* / %a * b
4+ -a - b
5< <= > >=a < b
6== !=a == b
7&&a && b
8 (último)||a || b

Sin paréntesis (confuso)

if (a > 0 && b > 0 || c == 5)

Con paréntesis (claro)

if ( (a > 0 && b > 0) || (c == 5) )

Regla de oro: ante la duda, usa paréntesis. No cuesta nada y evita errores difíciles de encontrar.

Ejemplo completo · Validación de edad para votar

Guía 6 – Estructuras Selectivas

Este es el ejemplo integrador de la guía. Reúne todo lo que hemos visto: lectura de datos, validación, operadores lógicos y if – else if – else.

#include <stdio.h>

int main() {
    int edad;

    printf("Ingrese su edad: ");
    if (scanf("%d", &edad) != 1) {          // validamos que sea un número
        printf("Error: debe escribir un numero\n");
        return 1;
    }

    if (edad < 0 || edad > 120) {           // validación de rango
        printf("Edad no valida\n");
    } else if (edad >= 18) {
        printf("Puede ejercer su derecho al voto\n");
    } else {
        printf("Aun no puede votar. Le faltan %d anios\n", 18 - edad);
    }

    return 0;
}

Qué practicamos aquí

  • Lectura de datos con scanf.
  • Validación de datos incorrectos.
  • Operador lógico ||.
  • Estructura if – else if – else.

Pruebas sugeridas

  • Edad -5 → "Edad no valida".
  • Edad 15 → "Aun no puede votar...".
  • Edad 18 → "Puede ejercer su derecho al voto".
  • Escribir "abc" → mensaje de error.

Tema 4 · Proyecto: Soluciones para la comunidad

Nutrición de los habitantes de mi comunidad

Aplicaremos todo lo aprendido —sintaxis básica, operadores y estructuras condicionales— para crear un programa en C que aborde una problemática real de nutrición en nuestra comunidad.

El programa debe incluir

  • Lectura de datos: pedir la información al usuario con scanf.
  • Procesamiento de información: hacer cálculos con operadores.
  • Presentación de resultados: mostrar conclusiones claras con printf.
  • Decisiones: usar if – else if – else para clasificar los resultados.
  • Validaciones: asegurar que el usuario ingrese datos correctos.

Cálculos que debe hacer el programa

Sumas, restas, promedios y decisiones basadas en condiciones.

Ejemplo guía · Calculadora nutricional (IMC)

#include <stdio.h>

int main() {
    float peso, talla, imc;

    printf("Peso en kg: ");
    scanf("%f", &peso);
    printf("Talla en metros: ");
    scanf("%f", &talla);

    // VALIDACIÓN de datos
    if (peso <= 0 || talla <= 0) {
        printf("Datos no validos. Intente de nuevo.\n");
    } else {
        imc = peso / (talla * talla);        // procesamiento

        printf("Su IMC es: %.2f\n", imc);    // resultado

        if (imc < 18.5) {
            printf("Clasificacion: Bajo peso\n");
        } else if (imc < 25.0) {
            printf("Clasificacion: Peso normal\n");
        } else if (imc < 30.0) {
            printf("Clasificacion: Sobrepeso\n");
        } else {
            printf("Clasificacion: Obesidad\n");
        }

        printf("Recomendacion: consulte con el area de salud del colegio.\n");
    }

    return 0;
}

Para tu proyecto

Puedes cambiar el cálculo por: promedio de comidas diarias, consumo de agua, porciones de fruta o comparación con la canasta familiar.
